Pentest Workflow ด้วย Burp Suite

5 ขั้นตอนหลัก ตั้งแต่ Recon จนถึง Report — ใช้ Burp เป็น core tool ตลอด

🔍
1. Reconnaissance & Setup
ตั้งค่า Browser → Burp Proxy → เปิด Intercept เพื่อดักจับ traffic ทั้งหมด รวมถึง configure scope ให้ถูกต้องก่อนเริ่ม
Proxy Intercept Scope Config Burp Browser TLS Certificate Setup
🗺️
2. Discovery & Mapping
ให้ Burp Spider / Crawler map เส้นทางทั้งหมดของ web app โดยอัตโนมัติ พร้อมดู Site Map เพื่อหา endpoint ที่น่าสนใจ และ enumerate parameters
Spider / Crawler Site Map DOM Invader Param Enum
⚡
3. Automated Scanning
รัน Burp Scanner เพื่อ detect vulnerability แบบ passive (ดู response) และ active (ส่ง payload) ครอบคลุม OWASP Top 10 + vulnerabilities จาก PortSwigger Research
Burp Scanner Active Scan Passive Scan OAST Testing BChecks
🔬
4. Manual Exploitation & Testing
ตรวจสอบและ exploit ช่องโหว่ที่ scanner พบ หรือ test สิ่งที่ automation miss ไป เช่น business logic bugs, privilege escalation, authentication bypass
Repeater Intruder (Brute/Fuzz) Sequencer Decoder Burp AI Autorize (BApp)
📋
5. Reporting & Remediation
Export ผลลัพธ์เป็น Report อัตโนมัติ (HTML/XML) พร้อม severity rating และ remediation guidance ส่งให้ Developer team แก้ไข จากนั้น retest เพื่อ verify fix
Auto Report Gen Issue Tracker Organizer Project Files Retest

🔄 Flow สรุป (ง่ายๆ)

Browser traffic  →  Burp Proxy  →  Site Map  →  Auto Scan  →  Manual Test  →  Exploit  →  Report  →  Fix  →  Retest ♻️
